核心功能

把「选中文字后的下一步」做得尽可能快

六项能力收敛成一个随选即出的浮动工具栏，用最少步骤完成高频动作。

全局划词

浏览器、记事本、Office、代码编辑器……任何可选中文字的地方拖选，工具栏自动跟随弹出，不抢占输入焦点。

智能打开

识别选中的 URL、本地文件路径与邮箱地址，自动调用对应的系统默认程序——浏览器、资源管理器、邮件客户端，一步直达。

一键复制 · 搜索

复制直达剪贴板，或用默认搜索引擎搜索选中词，搜索模板可配置，URL 自动正确编码。

插件化架构

所有动作都是插件，内置插件管理界面，支持加载外部 DLL、启停与配置；插件异常隔离，不影响主程序与其它插件。

多显示器 · 高 DPI

工具栏跟随鼠标所在屏幕弹出，Per-Monitor DPI 精确定位，跨屏不越界、图标不模糊。

托盘常驻 · 稳定

单实例运行、托盘菜单齐全；休眠 / 锁屏后自动重连钩子，5 秒无操作自动消失，运行日志落盘可查。

智能打开

选什么，就开什么

「打开」动作会自动识别文本类型，选择最合适的打开方式；无法识别时兜底为搜索。

URL

默认浏览器

http / https 链接直接在浏览器打开

本地路径

系统默认程序

图片、音乐、视频、文档按默认关联程序打开

邮箱地址

邮件客户端

识别邮箱格式，唤起默认邮件客户端写信

其它文本

默认搜索

无法识别或不确定时，兜底为浏览器搜索

插件与技术

能力即插件，扩展由你做主

把工具栏的每个动作都做成插件：内置三个核心插件，也欢迎加载你自己的外部 DLL。

统一插件接口实现 IPlugin 接口即可接入，主程序负责加载与调度，异常隔离。
内置插件管理界面插件列表、启停、加载 / 卸载、搜索模板配置，改动即时生效并持久化。
智能显示动作工具栏按钮按插件能力过滤：智能打开只对 URL / 路径 / 邮箱显示，界面不冗余。
查看插件开发指南 翻译插件仓库

技术栈

C# + WPF .NET 8 LTS 全局低层鼠标钩子 WH_MOUSE_LL UI Automation TextPattern 插件动态加载 AssemblyLoadContext JSON 配置持久化

选区捕获依赖 UI Automation 读取前台元素选区；浮层窗口无边框、置顶、不抢占焦点；self-contained 发布，免装 .NET 运行时。
